# Проекты

Здесь находятся две реализации учебного full-stack приложения «Мини-анкета»:

- `gigacode/fromMainQuestionsOnly/` — версия, созданная GigaCode: backend на Spring Boot/WebFlux, frontend на HTML/CSS/JavaScript и альтернативный вариант на Flutter Web, а также конфигурация Docker.
- `opencode/fromMainQuestionOnly/` — версия, созданная OpenCode: backend на Spring Boot/WebFlux, frontend на Flutter Web, общий OpenAPI-контракт и конфигурация Docker.

Основное предпочтение отдано **GigaCode**. При этом OpenCode и другие AI-агенты не исключаются — их результаты можно использовать для сравнения и дальнейшей работы.
