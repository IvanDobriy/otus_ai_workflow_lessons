# Вопросы для уточнения перед стартом проекта

## 1. Технологический стек

- **Backend**: пишем на spring webflux (Spring Boot 4)
- **Frontend**: dart, flutter (web)
- **Версия языка/рантайма**: java 25, Dart SDK version: 3.13.2 (stable), Flutter 3.47.2
- **Пакетный менеджер**: gradle для java(backend), pub(flutter)
- **Порт для сервера**: 8080

## 2. AI-инструментарий (важно для отчёта!)

- **Какой инструмент обкатываем?** Kimi Code CLI
- **Модель**: K3 thinking: high
- **Плагины/расширения IDE**: нет, только kimi-cli


## 3. Содержание анкеты

- **Какие 3–5 вопросов** будут в анкете? (например: имя, любимый язык программирования, оценка курса)

## 4. Архитектура и запуск

- **Структура репозитория**: монорепо (`backend/` + `frontend/` в одном репозитории)?
