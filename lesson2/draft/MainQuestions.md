# Вопросы для уточнения перед стартом проекта

## 1. Технологический стек

- **Backend**: на чём пишем — Python (FastAPI / Flask), Node.js/TS (Express / Fastify) или Go?
- **Frontend**: чистый HTML+JS или фреймворк (React / Vue)?
- **Версия языка/рантайма**: какая установлена локально (например, Python 3.x, Node 20+)?
- **Пакетный менеджер**: pip/poetry/uv для Python, npm/pnpm/yarn для Node?
- **Порт для сервера**: стандартный (8000/3000) или есть ограничения?

## 2. AI-инструментарий (важно для отчёта!)

- **Какой инструмент обкатываем?** Kimi Code CLI, Cursor, GitHub Copilot, Windsurf, Codeium, что-то ещё?
- **Модель**: какую используем (это надо зафиксировать в блоке «стартовый setup»)?
- **Плагины/расширения IDE**: что будет в setup?
- **Альтернативы**: какие инструменты вы рассматривали и почему отклонили (это блок отчёта — лучше знать заранее)?

## 3. Содержание анкеты

- **Какие 3–5 вопросов** будут в анкете? (например: имя, любимый язык программирования, оценка курса)
- **Типы ответов**: свободный текст, выбор из вариантов, шкала оценки?
- **Валидация**: нужна ли (обязательные поля, длина ответа)?

## 4. Архитектура и запуск

- **Структура репозитория**: монорепо (`backend/` + `frontend/` в одном репозитории)?
- **Как фронтенд получает данные**: backend отдаёт статику сам, или фронтенд открывается отдельно (тогда нужен CORS)?
- **Инструкция по запуску**: одна команда или два процесса (backend + frontend)?

## 5. Git и сдача

- **Репозиторий**: уже создан (GitHub/GitLab)? Публичный или приватный?
- **Кто коммитит**: коммиты делает AI-инструмент или вы вручную?
- **Скриншоты**: куда складывать в репозитории (папка `screenshots/` или `docs/`)?

## 6. Процесс работы с инструментом

- **Фиксация промптов**: ведём лог промптов в отдельном файле по ходу работы (`PROMPTS.md` → потом в `REPORT.md`)?
- **Стиль работы**: максимально делегируем инструменту (как требует задание) — инструмент генерирует структуру и код, вы только наблюдаете и направляете?
- **Намеренные эксперименты**: пробуем ли специально разные подходы/формулировки, чтобы собрать материал о неудачных попытках для отчёта?

---

**Вариант «по умолчанию» для быстрого старта**: Python + FastAPI + чистый HTML/JS, backend сам отдаёт статику (не нужен CORS), монорепо.
