## 4. Реализация backend
- Как сгенерировать `GET /questions` со списком 3–5 жёстко заданных вопросов: используй json файл с 3-5 вопросами
- Как сгенерировать `POST /answers` с приёмом и хранением ответов в памяти: map + логируй в stdout через logback
- Как обеспечить корректный формат данных (JSON) для обмена с frontend: сделай протокол через open api и потом его используй его для синхронизации работ
- Вопросы будут сделущих типов: текстовые, через checkbox (выбирается только один)

## 5. Реализация frontend
- Как загрузить вопросы с backend: выполнить http GET /questions, и на основе протокола построить анкету в ui
- Как отправить ответы на `POST /answers`: приложение должно сохранить ответы и отправить их обратно на бек
- Как показать сообщение «Спасибо!» после отправки: отобразить в центре экрана.

## 6. Запуск и проверка приложения
- Как запустить backend и frontend локально, нужно организовать gradle.kts сборку для backend и flutter проекта, в backend необходимо выполнять загрузку артефакта web приложения из отдельной конфигурации flutterWeb и распоковать его в каталок src/main/resources/static, публикацию артефакта делать через maven publish в mavenLocal, в backend добавить таски на распаковку, удаление артефакта
- Как проверить сценарий целиком: загрузка вопросов → заполнение → отправка → «Спасибо!»: проверять буду я вручную, удостоверься в соответсвии обработки протокола на беке и фронте
- Какие ошибки возникают при запуске и как их отлаживать в диалоге с ассистентом: старайся решить ошибки сборки самостоятельно, если в течении 3х раз не получится, то сообщи мне. смотри в stout ищи решение самостоятельно
